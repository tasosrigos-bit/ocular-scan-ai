# Data dictionary — manifest schema

All model-facing data is described by CSV manifests in `data/processed/`.
One row per image. Generated by `src/oct_cds/data/manifest.py` from the
`configs/data/*.yaml` configs. Never edit manifests by hand.

## Manifest files

| File | Source config | Purpose |
|------|---------------|---------|
| `train.csv` | `oct_c8.yaml` | Training set (OCT-C8 authors' train split) |
| `val.csv` | `oct_c8.yaml` | Validation — model selection, calibration, threshold tuning |
| `test.csv` | `oct_c8.yaml` | Internal held-out test (OCT-C8 authors' test split) |
| `external_clinic_optopol.csv` | `clinic_optopol.yaml` | **External validation only** — OPTOPOL REVO clinic B-scans, never trained on |

## Columns

| Column | Type | Description |
|--------|------|-------------|
| `image_path` | str | Path to the image, relative to repo root |
| `label_key` | str | Canonical class key: one of `AMD`, `CNV`, `CSR`, `DME`, `DR`, `Drusen`, `Macular Hole`, `Normal` |
| `label_id` | int | Class id 0–7, per `data/metadata/label_map.json` (frozen ordering) |
| `split` | str | `train` \| `val` \| `test` \| `external_test` |
| `dataset` | str | `oct_c8` \| `clinic_optopol` |
| `source` | str | Acquisition device/vendor when known (`oct_c8_mixed`, `optopol_revo`) |
| `patient_id` | str | Grouping key for leakage checks. OCT-C8 has no patient IDs → equals the image stem (`per_image`). |
| `eye` | str | `OD` \| `OS` \| `unknown` (OCT-C8: `unknown`) |
| `quality_flag` | str | `ok` \| `low_contrast` \| `blur` \| `artifact` \| `wrong_modality` \| `phi_suspected` — set by `quality_control.py`. Rows != `ok` are excluded from training but kept in the manifest. |
| `width` | int | Pixel width after ingest (pre-preprocessing) |
| `height` | int | Pixel height after ingest |
| `md5` | str | Checksum of the source file; used for dedup and provenance |
| `near_dup_of` | str | If set, `md5` of the image this is a perceptual near-duplicate of (`deduplicate.py`) |
| `grader` | str | Who assigned the label (`oct_c8_authors`, `clinic_ophthalmologist`) |
| `grading_date` | str | ISO date the label was assigned, when known |
| `reference_standard` | str | `oct_c8_label` \| `clinical_diagnosis` |
| `notes` | str | Free text (e.g. de-identification review, grading caveats) |

## Invariants (enforced by `tests/test_split_no_leakage.py` and `manifest.py`)

1. `label_id` and `label_key` are always consistent with `label_map.json`.
2. No `patient_id` appears in more than one of `{train, val, test}`.
3. Every `external_test` row has `dataset == clinic_optopol` and never appears in any other split.
4. `clinic_optopol` rows must have `split == external_test` (asserted; build fails otherwise).
5. Training consumes only rows where `split == train` **and** `quality_flag == ok`.
6. Class ids present in manifests are a subset of 0–7; external set may omit classes.
